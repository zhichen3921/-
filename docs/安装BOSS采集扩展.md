# 安装 BOSS 当前岗位采集扩展

这个扩展只在你主动点击后读取当前标签页中唯一、可见且处于活动状态的 BOSS 岗位详情。它不会自动翻页、扫描岗位列表、发送消息、投递简历或读取 Cookie、聊天记录和验证码。

## 一、启动本地投递台

1. 打开 PowerShell。
2. 进入项目目录：

   ```powershell
   Set-Location '<project-root>'
   npm start
   ```

3. 保持这个 PowerShell 窗口运行。
4. 在普通 Edge 中打开 [http://127.0.0.1:43127/](http://127.0.0.1:43127/)。

扩展只允许访问这个本机地址。旧的 `file://` 投递台不能生成扩展配对令牌。

## 二、加载扩展

1. 在 Edge 地址栏输入 `edge://extensions/` 并回车。
2. 打开页面左侧或右上角的“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择以下文件夹，不要选择其中某个文件：

   ```text
   <project-root>\extension
   ```

5. 在 Edge 工具栏点击拼图图标，将“投递台 · BOSS 当前岗位采集”固定到工具栏。

如果修改过扩展代码，请回到 `edge://extensions/`，在扩展卡片上点击“重新加载”。

## 三、配对投递台

1. 打开本地投递台的“更新中心”。
2. 点击“生成扩展配对令牌”。
3. 点击“复制令牌”。
4. 打开扩展弹窗，将令牌粘贴到“扩展配对令牌”。
5. 点击“保存并连接”。此时状态是“已配置”；首次岗位预览成功后才会变成“已验证连接”。

令牌保存在 Edge 扩展自己的本地存储中。它不是 BOSS 密码，也不能访问 BOSS 登录态。

本地服务每次重新启动都会生成新令牌。如果服务确认令牌失效，扩展会立即删除本地保存的旧令牌并回到配对界面；请回到更新中心重新生成并粘贴。

## 四、采集一个岗位

1. 使用你平时登录 BOSS 的普通 Edge 窗口，打开下列受支持页面之一：
   - 独立岗位详情页：页面具有唯一的 `/job_detail/...` 岗位链接。
   - 搜索结果中的展开详情：页面只有一个可见的活动岗位详情面板，而且该面板内含唯一的岗位详情链接。
   - 页面结构变化时的备用情况：页面提供唯一、有效的 `JobPosting` 结构化数据，并能确定唯一岗位详情链接。
2. 点击工具栏中的扩展图标。
3. 点击“采集当前岗位”。
4. 核对并按需修改岗位名称、公司、地点、薪资、链接和岗位描述。
5. 点击“重新评估”，查看匹配分和去向。
6. 点击“加入投递队列”。

匹配分低于 60 时，“加入投递队列”默认不可用。只有你明确勾选“仍然保存”后才允许保存。

扩展发现重复链接或重复岗位时会显示已有记录及状态；保存时由投递台合并记录，不会自动发起沟通。

以下页面不支持采集：聊天页、个人资料页、首页、只有岗位列表但未展开详情的页面、同时显示多个活动详情的页面，以及无法确定唯一岗位链接的页面。隐藏或非活动详情面板会被忽略。

## 常见问题

### 显示“投递台还没启动”

确认 `npm start` 的 PowerShell 窗口仍在运行，并能访问 [http://127.0.0.1:43127/](http://127.0.0.1:43127/)。

### 显示“请先打开一个 BOSS 直聘岗位”

确认当前标签页的网址属于 `https://zhipin.com` 或其子域名，并满足上面的受支持页面条件。仅属于 BOSS 域名还不够；扩展会拒绝聊天页、个人资料页、首页和未展开详情的岗位列表，不会根据页面文字猜测岗位。

### 部分字段显示“需补充”

BOSS 页面结构可能变化。请在预览表单中手动补全；扩展不会编造缺失信息。补充后点击“重新评估”。

### 令牌失效或返回 403

本地服务重启后旧令牌会失效。扩展收到失效响应后会删除旧令牌。到投递台更新中心重新生成令牌，再在扩展的“连接设置”中保存；保存表示“已配置”，成功预览一次后才表示“已验证连接”。

### 会不会导致 `about:blank`

扩展不以自动化或调试模式启动 BOSS，也不改变当前标签页地址。它只在点击时通过 `activeTab` 临时读取当前页面，因此不会执行此前导致专用自动化浏览器跳转的流程。

## 权限说明

- `activeTab`：仅在点击扩展后临时访问当前标签页。
- `scripting`：把当前岗位提取器注入当前标签页一次。
- `storage`：在扩展本地保存配对令牌。
- `http://127.0.0.1:43127/*`：发送预览和保存请求到本机投递台。

扩展没有申请 BOSS 的长期主机权限，也没有申请 cookies、history、debugger、downloads 等权限。
