# 投递台本地服务说明

## 启动方式

双击项目根目录中的 `打开投递台.cmd`。启动器会：

1. 检查 `http://127.0.0.1:43127/api/health`。
2. 仅在服务未运行时，以隐藏窗口启动项目内的 `server/server.mjs`。
3. 最多等待 10 秒确认服务就绪。
4. 从本地服务取得本次运行的迁移令牌。
5. 使用项目已有的 `.boss-edge-profile` 专用 Edge 配置打开投递台。

服务只监听 `127.0.0.1`，不会对局域网或互联网开放。日常数据保存在项目的 `data/state.json`；浏览器扩展配对令牌和服务写入令牌不会写入说明文件。

## 旧版数据迁移

首次升级时，启动器会打开旧版 `file://` 页面，并携带仅用于迁移的桥接参数。页面会读取原先 `applicationDesk.v2` localStorage，展示迁移确认框；你确认后，岗位、沟通状态、人工话术、精选批次和删除记录会复制到本地服务，然后页面自动跳转到 `http://127.0.0.1:43127/`。

- 旧 localStorage 不会被删除或改写。
- 服务端会记录迁移来源；以后双击启动器会直接打开本地服务版。
- 即使迁移请求被重复执行，同一岗位也不会重复添加。
- 如果页面提示没有旧版数据，可以直接打开 [本地投递台](http://127.0.0.1:43127/)；此时没有内容需要迁移。

迁移失败时不会设置成功状态，可以修复问题后再次双击启动器。

## 常见问题

- “10 秒内未启动”：确认已安装 Node.js，并检查端口 `43127` 是否被其他程序占用。
- “未找到 Microsoft Edge”：安装 Edge，或确认其位于系统标准安装目录。
- 页面无法读取数据：先访问 `http://127.0.0.1:43127/api/health`，应看到 `ok: true`。
- 扩展显示未连接：在投递台“更新中心”生成新的配对令牌，再粘贴到扩展中。

本启动器不会创建 Windows 定时任务，不会自动操作或登录 BOSS，也不会自动发送沟通内容。
