# 投递台使用说明

## 日常使用

1. 双击 `打开投递台.cmd`。
2. 在“投递队列”优先查看 75 分及以上的岗位。
3. 在“待复核”检查 60–74 分、信息不完整或要求偏高的岗位。
4. 使用岗位方向、公司、来源、区域、发布时间、毕业年份和沟通状态组合筛选。
5. 打开岗位原链接复核招聘状态，再复制个性化话术并由你亲自发送。
6. 沟通后把状态改为“已沟通”或“已回复”。

## 调整匹配偏好

在“求职偏好”中可以调整：

- 主要求职方向和冲刺方向；
- 主队列、待复核的最低分数；
- 接受的地点、毕业年份；
- 最少实习月数和每周到岗天数。

保存后，本地服务会重新评估尚未沟通的岗位；已沟通记录和人工话术会保留。

## 从 BOSS 采集当前岗位

先按 `docs/安装BOSS采集扩展.md` 加载本地扩展。登录 BOSS 后进入一个具体岗位详情页，点击扩展并选择“采集当前岗位”。扩展只读取当前可见岗位，不自动翻页、不扫描列表、不读取 Cookie 或聊天记录，也不会自动发送消息。

低于 60 分的岗位默认不保存；如果你确认需要保留，可在扩展预览中勾选强制保存。

## 更新岗位

“立即更新”只处理公开招聘来源，来源页面必须能核验公司和岗位名称；无法确定真实性的候选不会自动进入队列。登录后的 BOSS 岗位仍由浏览器扩展按当前页面采集。

当前版本没有创建每日 09:00 的系统定时任务。需要自动定时执行时，应在单独验收更新器后再启用。

## 数据与安全

- 本地服务数据：`data/state.json`。
- 旧版浏览器数据会保留，迁移不会删除它。
- JSON 导入、导出可用于人工备份。
- 投递台负责搜索、筛选、评分和话术生成；最终沟通和投递始终由你确认。
